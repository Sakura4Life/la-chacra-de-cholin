\# La Chacra de Cholin



Juego de granja en realidad aumentada (RA) para celular Android.



\## Estado del proyecto


En desarrollo



\## Requisitos



\- Windows con \*\*Visual Studio 2022\*\* (carga de trabajo "Desarrollo de juegos con Unity")

\- \*\*Unity 6.3 LTS, versión exacta `6000.3.26f1`\*\*, con módulo \*\*Android Build Support\*\* (OpenJDK y SDK/NDK incluidos)

\- \*\*Git\*\* y \*\*Git LFS\*\*

\- Celular Android compatible con ARCore



\## Cómo abrir el proyecto



1\. Instala Git y Git LFS, y ejecuta una vez `git lfs install`.

2\. Clona el repositorio en una ruta corta y sin tildes:

&#x20;  ```

&#x20;  cd C:\\'tu carpeta'

&#x20;  git clone https://github.com/<usuario>/la-chacra-de-cholin.git

&#x20;  cd la-chacra-de-cholin

&#x20;  git lfs pull

&#x20;  ```

3\. En Unity Hub: \*\*Add → Add project from disk\*\* y elige la carpeta del repo.

4\. Abre con la versión `6000.3.26f1`. La primera apertura tarda varios minutos.

5\. En Unity: \*\*Edit → Preferences → External Tools\*\* y elige Visual Studio 2022.



\## Datos técnicos



\- Plantilla: Universal 3D (URP)

\- Plataforma: Android, orientación vertical (Portrait)

\- Package name: `com.aki4life.lachacradecholin`
